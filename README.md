MIMAROPA Integrated Networks of DOST Scholars website is for the community of DOST scholars and aspiring DOST Scholars.
This website includes DOST-SEI & DOST MIMAROPA news, and events. With added features of a Social and Event Calendar to display pending and upcoming events of the organization.
Moreover, a dedicated community page that provides users access or links to communities of DOST MIMAROPA such as Discord and Facebook community.
